# AgentX Workmate 1.0.6

## vi
- Server MCP chạy bằng uvx (các gói Python, như nhiều server tuyển chọn trên AgentX Hub) nay dùng được uv đi kèm AgentX, không cần tự cài uv.
- Khi máy thiếu chương trình mà một server MCP cần (uv, Node.js…), thẻ của nó trong Tiện ích ghi rõ "Thiếu uv" và cách khắc phục, thay vì báo lỗi kết nối chung chung.
- Nếu đang dùng desktop 1.0.1–1.0.3, tải và chạy bộ cài 1.0.6 một lần từ trang tải về; desktop 1.0.4 trở lên có thể cập nhật ngay trong ứng dụng.

## en
- MCP servers launched with uvx (Python packages, like many curated servers on AgentX Hub) now use the uv that ships with AgentX; no separate uv install is needed.
- When a server needs a program this computer lacks (uv, Node.js…), its card in Utilities says "Missing uv" and how to fix it, instead of a generic connection error.
- Desktop 1.0.1–1.0.3 users should download and run the 1.0.6 installer once; desktop 1.0.4 and later can update directly in the app.
