# AgentX Workmate 1.0.10

## vi
- Lệnh agentx uninstall trong terminal giờ cũng mặc định giữ dữ liệu, giống trình gỡ cài đặt Windows và Cài đặt trong ứng dụng: lệnh gỡ phần chạy của agent, lệnh agentx và lối tắt, còn hội thoại, cài đặt và key model ở lại. Muốn xoá cả dữ liệu thì chạy agentx uninstall --full, hoặc chọn mục 2 khi lệnh hỏi.
- Trên Windows, đừng gỡ bản cũ trước khi cài bản mới: trình gỡ cài đặt của các bản trước 1.0.9 vẫn tích sẵn ô xoá dữ liệu. Hãy cập nhật ngay trong ứng dụng, hoặc chạy bộ cài 1.0.10 đè lên bản cũ.
- Nếu đang dùng desktop 1.0.1–1.0.3, tải và chạy bộ cài 1.0.10 một lần từ trang tải về; desktop 1.0.4 trở lên có thể cập nhật ngay trong ứng dụng.

## en
- The agentx uninstall command now also keeps your data by default, like the Windows uninstaller and the app's Settings: it removes the agent runtime, the agentx command and the shortcuts, while chats, settings and the model key stay. To delete the data as well, run agentx uninstall --full, or pick option 2 when it asks.
- On Windows, do not uninstall the old version before installing the new one: the uninstaller of versions before 1.0.9 still ticks the delete-data box for you. Update from inside the app, or run the 1.0.10 installer over the old version.
- Desktop 1.0.1–1.0.3 users should download and run the 1.0.10 installer once; desktop 1.0.4 and later can update directly in the app.
