## vi
- Xem, sửa và xoá từng ghi nhớ trong Cài đặt → Bộ nhớ; bản đồ bộ nhớ cập nhật đúng mục ngay cả khi danh sách thay đổi.
- Cải thiện thao tác nhiều tab: nút đóng trực tiếp, mở hội thoại trong tab mới đưa bạn đến đúng tab, và khung trò chuyện chia đôi luôn giữ thanh tab.
- Artifacts tập trung vào tệp và sản phẩm AgentX đã tạo; trạng thái công cụ, nội dung lỗi và yêu cầu chờ duyệt rõ ràng hơn, theo ngôn ngữ hiển thị.
- Tự làm mới danh sách model theo quyền tài khoản, loại bỏ lựa chọn không còn được cấp và phục hồi các trường hợp lỗi tham số reasoning hoặc lỗi tham số do gateway thêm vào.
- Sửa hội thoại đã xoá xuất hiện trở lại dưới dạng rỗng; cải thiện làm mới đăng nhập SSO và độ chính xác của báo cáo sử dụng.
- Tích hợp WebMate 1.0.13; cải thiện cài đặt, kết nối trình duyệt, cập nhật và nạp lại MCP. Các công cụ Python riêng không còn bị ảnh hưởng bởi môi trường Python của ứng dụng.
- Làm mới màn hình trò chuyện trống và hiệu ứng đang suy nghĩ; sửa lỗi chữ gợi ý khi sửa tin nhắn, tên dự án dài và tên tab chưa được dịch.
- Bộ cài macOS Apple Silicon và Windows x64 tiếp tục chứa sẵn runtime. Cài đè lên bản hiện tại để giữ dữ liệu; Windows 1.0.x cần tải và chạy bộ cài mới một lần. Dịch vụ đồng bộ hội thoại Second Brain cũ đã được gỡ bỏ; hội thoại và bộ nhớ cục bộ được giữ lại.

## en
- View, edit and delete individual entries in Settings → Memory; memory-map edits target the entry you saw even when the list changes.
- Better multi-tab controls: visible close buttons, opening a chat in a new tab takes you there, and split chat panes retain their tab bars.
- Artifacts focuses on files and deliverables AgentX created; tool status, errors and pending approvals are clearer and follow the display language.
- Model catalogs refresh with account grants, unavailable selections are retired, and unsupported reasoning or gateway-injected parameter errors can recover.
- Deleted chats no longer return as empty conversations; SSO refresh and usage reporting are more reliable.
- Includes WebMate 1.0.13 with installation, browser connection, update and MCP reload fixes. External Python tools no longer inherit the app's Python runtime paths.
- Refreshed empty-chat and thinking visuals; fixes for edit-message placeholders, long project names and untranslated tab titles.
- macOS Apple Silicon and Windows x64 installers continue to include the runtime. Install over the existing copy to keep data; Windows 1.0.x requires a one-time manual in-place update. Retired Second Brain conversation sync has been removed; local conversations and memory are retained.
