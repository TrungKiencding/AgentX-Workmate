# AgentX Workmate 1.0.5

## vi
- Khắc phục vòng lặp cập nhật khi mở lại: agent mới không còn bị nhận nhầm là cũ khi lịch sử Git chưa đầy đủ.
- Chặn trình cài tự đưa agent về phiên bản thấp hơn; xác minh phiên bản sau cài trước khi hoàn tất.
- Ghi nhận đúng commit đã cài và dọn shortcut AgentX cũ trên Windows để mở đúng ứng dụng mới.
- Giữ nguyên cài đặt, cuộc trò chuyện và khoá model khi nâng cấp.
- Nếu đang dùng desktop 1.0.1–1.0.3, tải và chạy bộ cài 1.0.5 một lần từ trang tải về; nút cập nhật của các bản cũ chỉ nâng phần agent. Desktop 1.0.4 có thể cập nhật ngay trong ứng dụng.

## en
- Fixes the repeated startup update: a newer agent is no longer mistaken for an older one when Git history is incomplete.
- Prevents installers from downgrading an existing agent and verifies the installed version before completing an update.
- Records the actual installed commit and removes legacy AgentX shortcuts on Windows so the updated app opens.
- Keeps settings, conversations and model keys during upgrades.
- Desktop 1.0.1–1.0.3 users should download and run the 1.0.5 installer once; their old update button only updates the agent. Desktop 1.0.4 can update directly in the app.
