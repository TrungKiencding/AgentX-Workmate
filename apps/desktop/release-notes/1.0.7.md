# AgentX Workmate 1.0.7

## vi
- Danh sách công cụ MCP dùng dạng chuẩn v2, giống hệt AgentX Hub: danh sách hub duyệt đúng như server gửi (kể cả khi server gửi thêm trường ngoài đặc tả, như chrome-devtools-mcp) khớp với cái Workmate đọc được, nên các công cụ đó không bị khoá.
- Gồm mọi thay đổi của 1.0.6: server MCP chạy bằng uvx dùng được uv đi kèm AgentX, và thẻ MCP báo rõ khi máy thiếu runtime.
- Nếu đang dùng desktop 1.0.1–1.0.3, tải và chạy bộ cài 1.0.7 một lần từ trang tải về; desktop 1.0.4 trở lên có thể cập nhật ngay trong ứng dụng.

## en
- MCP tool lists use the v2 canonical form, identical to AgentX Hub: a list the hub approved exactly as the server sent it (even with extra fields outside the spec, as chrome-devtools-mcp sends) matches what Workmate reads, so those tools are not locked.
- Includes everything in 1.0.6: MCP servers launched with uvx use the uv that ships with AgentX, and an MCP card says when a runtime is missing.
- Desktop 1.0.1–1.0.3 users should download and run the 1.0.7 installer once; desktop 1.0.4 and later can update directly in the app.
